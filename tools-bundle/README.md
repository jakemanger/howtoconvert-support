# Conversion tools

Command-line conversion tools for integrating file conversion into apps, scripts and workflows.

Prebuilt downloads for macOS, Windows and Linux, including Apple Silicon, save you from finding or compiling each tool yourself. Use the tools individually or install them together.

Fixed versions, corresponding source and build instructions belong together with each release, making each release easier to reproduce and distribute under the tools’ respective licenses.
